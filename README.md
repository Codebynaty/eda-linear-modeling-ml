Este projeto apresenta uma análise exploratória completa de um conjunto de dados reais relacionados à saúde, com o objetivo de identificar padrões, variabilidade, fatores de risco e relações entre indicadores fisiológicos, demográficos e comportamentais — incluindo idade, IMC, colesterol, triglicerídeos, frequência cardíaca, horas sedentárias e níveis de atividade física.

O estudo inclui:

🔍 Etapas Realizadas

Tratamento e limpeza inicial dos dados

Estatística descritiva (médias, medianas, dispersão, separatrizes)

Análise de distribuições (histogramas, assimetrias, outliers)

Correlações entre variáveis e risco cardíaco

Interpretação dos biomarcadores metabólicos

Identificação de anomalias e padrões críticos

Construção de insights acionáveis

📊 Principais Resultados

36% da população apresenta risco cardíaco elevado

Colesterol, triglicerídeos e IMC foram os maiores influenciadores de risco

Variáveis de estilo de vida mostraram baixa correlação direta com o risco

Forte presença de outliers metabólicos que indicam potencial risco clínico

Idade, peso e fatores genéticos/metabólicos se destacam como determinantes

🧠 Competências Demonstradas

Análise de dados avançada

Interpretação estatística aplicada a saúde

Construção de insights baseados em evidências

Relatórios técnicos estruturados

Lógica analítica e comunicação clara

💼 Tecnologias Utilizadas

Python (Pandas, NumPy, Matplotlib)

Excel / ferramentas estatísticas

Metodologia de modelagem linear para aprendizado de máquina
